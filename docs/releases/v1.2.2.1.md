# CCH Bar v1.2.2.1

更新内容：

- 上游倍率页允许未匹配到上游 key 的渠道先勾选；勾选这类渠道时会刷新 snapshot 重新匹配，新渠道不需要额外操作按钮。
- 新增上游登录态失效检测：Sub2API / new-api 返回未授权时保留上次可用的倍率、余额和匹配信息，并在上方站点卡片显示「登录失效」。
- 登录态失效站点保留在「可同步上游」分组，不再混入下方「待配置」区域；失效状态不会使用旧 snapshot 自动同步倍率。
- 登录态失效站点新增橘黄色「重新获取」按钮，复用现有登录态配置流程。
- 新增 snapshot 过期检测：本地渠道新增后，进入上游倍率页会自动刷新旧 snapshot，避免新增渠道长期显示未匹配。
