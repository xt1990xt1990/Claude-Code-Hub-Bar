# CCH Bar v1.2.2

更新内容：

- Mini 探针设置页重排：运行时段、探针频率和平均首字节统计控制更紧凑，拖动时会同时显示当前值。
- 上游倍率页增强：渠道名旁显示只读分组，倍率旁复用渠道页 Mini 探针开关、状态、历史和模型设置。
- 上游倍率卡片新增「本轮已调整」指示器，用于核对手动或自动同步实际改写了哪些渠道倍率。
- 顶部分组筛选改为 tab 下划线样式，与每行的渠道分组标签区分开。
- 新增 GLM 模型品牌图标，并收紧 OpenAI 模型名识别，减少 `o1/o3/gpt` 子串误判。
- 后端错误消息显示前会压缩、截断并过滤 HTML，避免长错误撑爆界面。
- 修复若干稳定性细节：关闭自动更新检查后取消后台 timer、钥匙串并发写入 duplicate 时自动重试、日期解析缓存加锁、设置窗口关闭后释放引用。
