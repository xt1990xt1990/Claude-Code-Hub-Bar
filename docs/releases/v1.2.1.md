# CCH Bar v1.2.1

更新内容：

- 新增 Mini 探针系统：可在设置中开启总开关，并在渠道行单独启用后台模型测试探针。
- Mini 探针支持渠道级测试模型、探针频率、运行时段和跨午夜时间段。
- 开启探针后会主动运行第一次；后台调度增加防抖、并发上限、失败退避和系统唤醒后的网络状态检查。
- 探针历史显示最近状态针，平均首字节只统计绿色成功样本；失败样本不再显示或污染首字节统计。
- 渠道模型测试接入 CCH 首字节和总延迟解析，支持同时展示 TTFB 与总耗时。
- 优化总览最近请求布局，长渠道名和长模型名按方案 A 自适应截断，减少中间空白。
- 优化日志行、探针按钮、状态针和 popover 细节，提升密集信息展示稳定性。
