# CCH Bar v1.2.5

更新内容：

- 渠道页新增置顶按钮，常用渠道可以固定在列表顶部，置顶状态会在重启后保留。
- 上游登录态获取改为共享 Chrome 登录窗口，减少不同上游站点之间反复登录的情况。
- 上游登录态导入会保存浏览器 User-Agent，并在 cookie-only 登录态缺少 User-Agent 时使用浏览器 UA 回退。
- 修复部分 new-api 站点余额接口变更后无法读取余额的问题，兼容通过 profile 接口返回余额的站点。
- 上游请求会先保留 HTTP 状态和 Cloudflare 响应头，再解析 JSON，避免把 Cloudflare 验证页误判为登录失效。
