# CCH Bar v1.2.7

更新内容：

- 修复已勾选渠道偶发长期停留在“待应用”的问题；同步失败或与其他刷新重叠时会自动重试，不再需要取消后重新选择。
- 修复上游余额刷新成功后状态仍异常、倍率快照覆盖余额，以及启动后余额未及时更新的问题。
- 修复 CCH 渠道 Key 临时读取不完整时覆盖已有匹配的问题；失败时会保留最近一次有效倍率和余额。
- Sub2API access token 改为提前两小时续期，避免按小时轮询错过过期窗口；没有 refresh token 时仍会继续使用尚未过期的 access token。
- 加强 Chrome 登录态导入和 Cookie 轮换处理，避免旧浏览器状态、Cloudflare 验证和刷新响应被误判为有效登录。
- 限制上游并发请求并完善瞬时失败保护，降低大量渠道同时刷新时的请求压力和状态抖动。
